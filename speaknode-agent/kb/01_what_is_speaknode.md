Common questions
Everything you need to know about SpeakNode
What is a voice AI agent and how is it different from a chatbot?
A voice AI agent answers and places phone calls, understands speech, and runs actions in your business systems. A chatbot stops at text. SpeakNode agents talk and act — update a CRM record, book a meeting, charge a card, route a ticket — across 500+ integrations from one no-code workflow.
Can a voice AI agent integrate with my CRM (HubSpot, Salesforce, GoHighLevel)?
Yes. SpeakNode runs on the Latenode workflow engine with native connectors to HubSpot, Salesforce, Follow Up Boss, GoHighLevel, and 500+ other systems. The voice agent triggers the workflow; the workflow updates the CRM. No glue code, no Zapier in the middle.
How much does an AI voice agent cost?
SpeakNode charges per voice minute — $0.07/min at the entry tier, dropping to $0.02/min at high volume. The first 250 minutes are free. Concurrency is free up to 10 lines. AI provider costs (LLM, STT, TTS) are billed separately in your provider account.
Do I need to code to build a voice AI agent on SpeakNode?
No. The workflow builder is no-code drag-and-drop, the same engine that powers Latenode. Developers can drop into JavaScript or Python when they want to; everyone else can ship a working agent in an afternoon.
What languages and AI models does SpeakNode support?
SpeakNode supports 30+ languages and 300+ AI models — OpenAI (GPT family), Anthropic Claude, Google Gemini, Deepgram for speech-to-text, ElevenLabs for text-to-speech, and more. Bring your own provider key; pick the model and the voice AI software stack that fits each agent's job.

## Features Overview
Overview of Speaknode platform capabilities for AI voice agents
Speaknode is a platform for creating and managing AI voice agents that communicate with users via phone calls, web widget, or direct browser connection.

## Core Capabilities
| Feature | Description
| AI Agents | Create and configure voice agents with custom behavior, personality, and knowledge
| Voice & Communication | Real-time voice conversations powered by WebRTC
| Website Widget | Embeddable widget for adding a voice agent to any website
| Telephony | Inbound and outbound phone calls via Twilio and VoxImplant
| Outbound Campaigns | Mass outbound calling campaigns with dynamic variables
| Tools & Integrations | Connect agents to external APIs and webhooks
| Analytics | Conversation history, recordings, and telemetry
| Teams & Spaces | Workspaces for team collaboration
| Billing | Usage-based billing with plan management

## How It Works
User configures agent → Agent dispatched to LiveKit room →
AI agent joins and starts conversation →
Session recorded and analyzed
Configure — set up the agent's behavior: system prompt, voice, language, tools
Deploy — embed the widget on your site, connect a phone number, or use the API
Communicate — the agent handles conversations in real time
Analyze — review recordings, transcripts, and telemetry data
