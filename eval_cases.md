# Eval test cases: Nika

## How to read

1. «Вопрос» / «Диалог» — что пишет человек; несколько реплик через → — это диалог.
2. «Код проверяет» — проверки программой, всегда одинаковые.
3. «Судья проверяет» — что оценивает модель-судья по смыслу.
4. Кейс пройден, только если прошли обе проверки. Каждый кейс прогоняется 3 раза.
5. «Откуда»: 🔁 Leo — из настоящего провала или ловушки голосового агента Leo; 🔍 — добавлено после независимой проверки; ✏️ — придумано для Ники.
6. Правильный ответ берётся из базы Ники ([kb/](speaknode-agent/kb/)), а не из ответов Leo.

## Run rules

1. Чистое состояние: перед каждым прогоном файлы заявок, записей и передач оператору пустые.
2. Замороженные часы: будний день 10:00 UTC, для D1 — суббота.
3. Числа ищутся гибко: `0.07`, `0,07` и «7 центов» — одно и то же.
